# Partner logos

Drop official partner logo files in this folder, then set the matching
`logo:` path in `lib/site.ts`. Use SVG where possible (sharpest); otherwise
a transparent-background PNG at ~2x display size.

Recommended filenames (already mapped — just set the `logo` field):

| Partner                          | File                          | `logo:` value                     |
|----------------------------------|-------------------------------|-----------------------------------|
| NMB Bank                         | nmb.svg                       | "/partners/nmb.svg"               |
| CRDB Bank                        | crdb.svg                      | "/partners/crdb.svg"              |
| SELF Microfinance Fund           | self.svg                      | "/partners/self.svg"              |
| Starlink Gulf Trading Company    | starlink.svg                  | "/partners/starlink.svg"          |
| Magic Builders International      | magic-builders.svg            | "/partners/magic-builders.svg"    |
| Climax Company Ltd               | climax.svg                    | "/partners/climax.svg"            |

## Important
Only display a partner's logo once you have permission to use their
trademark (especially the banks: NMB, CRDB, SELF). Obtain logos from each
company's official brand kit / press page or directly from your contact there.

Until a logo is added, the site shows a clean wordmark placeholder — no action
needed for it to look finished.
